# Personal Android APK

This is an Android wrapper for the original Build Solver frontend. The original solver logic is not modified.

## Build on GitHub
1. Open the **Actions** tab.
2. Choose **Build Android APK**.
3. Press **Run workflow**.
4. After the run succeeds, download the **Wynncraft-Recipe-Solver-Android** artifact.
5. Extract the ZIP and install `app-debug.apk` on Android.

The APK is a personal-use debug build, not a Play Store release. The frontend is packaged locally; external links and any remote services still require internet access.

Original upstream license and attribution remain in the repository.
